Struct ParameterMemrefOutput

pub struct ParameterMemrefOutput<'a> { /* private fields */ }
Expand description

A memory-reference output parameter.

The host provides a write-only buffer. The TA fills the buffer and report the final number of valid bytes via ParameterMemrefWrite::set_updated_size.
