Expand description

Convert a single raw parameter into a type-safe Rust wrapper.

§Safety

Implementors must validate that raw_type matches the expected parameter type and that raw_param has been correctly initialized by the TEE runtime before reading any fields.

Required Methods§

Source

unsafe fn from_raw( raw_type: RawParamType, raw_param: &'a mut TEE_Param, ) -> Result<Self>

Construct Self from a raw parameter.

§Safety

Caller must ensure raw_type and raw_param are a consistent pair delivered by a TEE entry-point invocation (e.g. TA_InvokeCommandEntryPoint).

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
